SIMCA (https://arxiv.org/abs/2610.03503) calibrates the two scalar guidance weights of a training-free posterior sampler by a 2 by 2 linear least-squares fit of the unconditional field plus a measurement term to the diffusion or flow-matching regression target, either independently at each time or along one Euler trajectory per sample. Install with `pip install -e .`, then run `python -m simca.demo` and `pytest`. This CPU toy does not reproduce the paper's image experiments. There is no pretrained image model and no PSNR or SSIM, Phi is an Euler step on the probability-flow ODE rather than a 1000-step DDIM sampler, the measurement term is the raw gradient of the squared residual so the weight absorbs the proportionality constant, a ridge of 1e-8 is added only when the normal matrix is singular, and the paper's Algorithm 1 listing writes the state update at the next index while the sampler equation and this code step toward smaller t. The demo is a dimension-8 Gaussian linear inverse problem, not an image batch.
